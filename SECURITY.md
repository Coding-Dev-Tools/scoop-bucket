# Security Policy

## Supported versions

This bucket supports the manifests on the default branch. Each manifest points to an upstream project; security support for the packaged application follows that project's own policy.

## Reporting a vulnerability

Email **security@codingdevtools.com** to report a vulnerability privately. You may also use GitHub's private vulnerability reporting if it is enabled for this repository. Do not include exploit details in a public issue.

Include the affected manifest, version, download URL, expected hash or signature, and enough reproduction detail to verify the report. For a vulnerability in the packaged application rather than its Scoop manifest or delivery metadata, also report it to the upstream project.

Do not publish credentials, exploit code, or other sensitive details in a public issue. Maintainers will acknowledge a report, validate its scope, update or disable affected manifests as appropriate, and coordinate disclosure with the upstream project.
